# FoldPredict UI Design

## Direction: Folded Glass / Signal Lab

A cool, precise prediction-market surface — not a dashboard, not a newspaper, not cream-and-terracotta.

The first viewport reads as one composition: a full-bleed fold plane (glass device silhouette) with **FoldPredict** as the dominant brand mark, one question, one sentence, and one CTA pair.

## Tokens

| Token | Value | Role |
|-------|-------|------|
| `--ink` | `#0B1F2A` | Primary text |
| `--mist` | `#E7F0F4` → `#C9DCE6` | Atmospheric field |
| `--signal` | `#0B6EFD` | Primary action / active signal |
| `--fold` | `#1FA7A0` | Secondary accent (hinge / trust) |
| `--muted` | `#4A6570` | Supporting copy |
| `--danger` | `#C23B22` | Errors |
| `--display` | Syne | Brand + headlines |
| `--sans` | Sora | UI body |
| `--mono` | JetBrains Mono | Addresses / hashes |

## Hero rules

1. Brand name is the largest type on the page.
2. One headline question only.
3. One supporting sentence.
4. One CTA group (Place a bet / View market).
5. One dominant edge-to-edge visual: the fold plane.
6. No stats, schedules, chips, or floating badges in the first viewport.

## Motion

1. **Brand in** — FoldPredict rises and clarifies (0.85s).
2. **Fold sweep** — glass panels ease open along the hinge (1.4s, looping subtle breathe).
3. **Signal underline** — nav active state + primary CTA ink fill transition.

## Inner pages

Single-purpose sections: one headline, short lede, sparse detail rows (no card grids). Betting form and timeline stay interaction-first, unboxed.
