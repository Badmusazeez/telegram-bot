Transfer to Figma

Each phone is a named data-figma-frame at 440×956 (iPhone 17 Pro Max). Design tokens live in figma/design-tokens.json.

  • Authenticate the Figma MCP in Cursor Desktop, then ask to “push SkyLease screens to Figma”.
  • Or open this page, screenshot each frame, and place on an iPhone 17 Pro Max artboard.
  • Import colors/typography from figma/design-tokens.json as Variables.
